# About the project

This is an "Operational System" running in a CYD Board with ESP32.
It is designed to have pink pastel based colors on his UI.

We are building few apps. Such like a Space invaders game, note taken, clock, configurations and a calculator.

# Things to know about the development

The framework we're using is the Arduino framework under the ESP32 using the PlatformIO in IDE extension.

- Use snakecase in filenames and vars names.
- Don't take too many commentaries, view better var names.
- ALWAYS make the code thinking about the next session, none knowledge should be losed.
